## AegisBrowser 解决什么问题？

- **解决多账号关联封店难题**：面向跨境电商（Amazon / TikTok Shop / Shopee / Etsy）与海外社媒多账号矩阵运营，为每个环境分配完全物理隔离的本地数据空间与独立设备硬件指纹（画布、图形渲染、声卡、字体、屏幕特征等），从根源杜绝同机多登串号关联。
- **解决代理断连漏真机 IP 与时区穿帮**：每次启动窗口前强制执行**出口网络预检**，线路异常或意外暴露国内网络时立即熔断拦截，并根据真实出口地区自动匹配对应国家的时区、语言与地理位置。
- **解决传统指纹浏览器臃肿卡顿与风控识别**：告别动辄数百 MB 的重型客户端；人工运营环境纯净无自动化调试痕迹，从容应对严苛平台风控校验；多账号共享单一只读浏览器内核，关窗自动清理冗余音视频与图片缓存。
- **解决多设备协同泄密与同号撞车**：核心店铺登录状态与免密箱在本地完成端到端加密后再同步，云端不留存任何明文数据，并配备防异地同时在线的会话互斥锁。

## 首次安装放行说明

首次安装或启动时如遇操作系统默认安全拦截提示，按以下步骤放行即可：

- **Windows 安全提示**：  
  若弹出 *“Windows 已保护你的电脑”*，点击弹窗上的 **「更多信息」→「仍要运行」** 即可正常完成安装。
- **macOS 安全提示**：  
  打开 `.dmg` 将 `AegisBrowser.app` 拖入 **「应用程序（Applications）」** 后，若首次启动提示 *“无法验证开发者”* 或 *“已损坏，无法打开”*，请打开「终端（Terminal）」执行以下命令解除隔离标记：
  ```bash
  sudo xattr -rd com.apple.quarantine /Applications/AegisBrowser.app
  ```
